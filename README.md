# SEIR-Based COVID-19 Analysis of Maharashtra

A Python-based project that uses the **SEIR epidemiological model** to study the spread of COVID-19 in Maharashtra, India, using real-world case data.

The project covers data preprocessing, implementation of the SEIR model, parameter estimation, and comparison of model predictions with reported cases.

## 1. Model Overview

The SEIR model divides a population into four compartments:

- **S – Susceptible:** Individuals who can become infected.
- **E – Exposed:** Individuals who are infected but not yet infectious.
- **I – Infectious:** Individuals capable of transmitting the infection.
- **R – Recovered:** Individuals who have recovered and left the infectious compartment.

The movement of individuals between these compartments is described by the following differential equations:

**1. Susceptible population**

dS/dt = −βSI/N

**2. Exposed population**

dE/dt = βSI/N − σE

**3. Infectious population**

dI/dt = σE − γI

**4. Recovered population**

dR/dt = γI

Here:

- **N:** Total population.
- **β (Beta):** Transmission rate.
- **σ (Sigma):** Rate at which exposed individuals become infectious.
- **γ (Gamma):** Recovery rate.

The basic reproduction number (R₀) represents the average number of secondary infections generated by one infectious individual in an initially susceptible population.

For this simplified SEIR model:

**R₀ = β/γ**

## 2. Dataset

The analysis uses state-wise COVID-19 data from the COVID19India repository.

**Source:** [COVID19India Dataset](https://data.covid19india.org/csv/latest/states.csv)

- **State:** Maharashtra
- **Study period:** 9 March 2020 – 31 December 2020
- Daily new confirmed cases are calculated from consecutive differences in cumulative confirmed cases.

## 3. Methodology

1. **Data preprocessing:** Extracted Maharashtra's records, processed dates, checked data quality, and calculated daily new cases.
2. **SEIR implementation:** Implemented the compartmental model using Python and numerical differential equation solving.
3. **Parameter estimation:** Used nonlinear least-squares optimisation to estimate model parameters by fitting predicted cases to reported cases.
4. **Model evaluation:** Compared predicted and observed daily cases using RMSE and R-squared.

## 4. Results

The fitted model produced the following results:

| Metric | Value |
|---|---:|
| Basic reproduction number (R₀) | 1.3639 |
| Root Mean Squared Error (RMSE) | 2058.88 |
| R-squared (R²) | 0.8835 |

The model captures the broad epidemic trajectory, including the initial growth, peak, and subsequent decline.

However, it underestimates the observed peak and does not fully capture fluctuations in daily reported cases or the slower decline towards the end of the study period.

## 8. Limitations

- The model assumes a well-mixed population and does not account for differences in individual contact patterns.
- Transmission and recovery parameters are assumed to remain constant throughout the study period.
- Reported cases do not represent all actual infections.
- The relationship between modelled infections and reported cases is simplified and does not explicitly account for reporting delays.
- Negative daily case values caused by retrospective reporting revisions are replaced with zero during preprocessing.
- Multiple parameter combinations may produce similar fitted curves, making individual parameter estimates difficult to identify uniquely.
- Evaluation metrics are calculated on the same data used for fitting and therefore do not establish predictive performance on unseen data.
